Flint Networker

A Windows network diagnostic tool for identifying whether internet disconnections or latency originate from the PC, router, external connection, or DNS.

Quick Check

  1. Run the program.
  2. Click Quick Check.
  3. When the check is complete, review the overall diagnosis at the bottom.
  4. If needed, click Save Log to save the results.

The Quick Check examines the following:

  • Local IP address
  • Default gateway
  • 20 pings to the router
  • 20 pings to Cloudflare and Google DNS
  • DNS lookup
  • Packet loss and latency
  • Overall diagnosis of where the problem occurs

Continuous Monitoring

Use this feature to detect intermittent internet disconnections.

  1. Select the monitoring interval.
  2. Click Start Continuous Monitoring.
  3. Leave the program running until a disconnection occurs.
  4. Click Stop Continuous Monitoring when you are finished.

The tool continuously checks the router and external internet connection while recording the cumulative number of failures.

Traceroute

Click Traceroute to view the network path to the external internet.

System Requirements

This tool is designed for Windows because it uses the Windows ping, route, nslookup, and tracert commands.

Run:

python networker.py
