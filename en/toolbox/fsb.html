Flint Site Builder

Version: 1.0.0

Flint Site Builder

A GUI-based tool for building static HTML websites from Markdown documents.

Flint Site Builder preserves your original Markdown files while allowing you to customize menus, banners, layouts, and CSS. The completed website is generated in a separate output folder. Markdown documents that are not included in the top, bottom, left, or right menu layouts can also be converted into standalone HTML pages using the HTML Conversion feature.

Getting Started

  1. Create a new project or open an existing one.
  2. Link Markdown documents from your working folder to the menus.
  3. Configure the menus, banners, and template design.
  4. Preview your website, then click Generate Site.

Menu Configuration

Separate menu items with commas and place subcategories inside square brackets [].

Home, South Korea, Travel[Seoul, Gangwon-do], Stories

Each menu item can be linked to a Markdown document or an email address.

Template Designs

Flint Site Builder provides four HTML layouts based on menu placement: top, bottom, left, and right.

Each layout supports three design styles:

  • Default : A standard design
  • Unlimited Banner : A design with an expanded banner width
  • Menu Jump : A design that replaces the sticky menu with a button that jumps to the menu section

The four HTML layouts use CSS-based styling, providing a total of 12 built-in design options.

Markdown Links

You can link Markdown documents using standard .md links.

[Seoul](Seoul.md)

When generating a website or converting Markdown to HTML, local .md links are automatically converted to .html links. External URLs, email links, image links, and other links remain unchanged.

HTML Conversion

The HTML Conversion feature allows you to convert Markdown documents into standalone HTML pages without including them in any of the four website layouts.

When you select a folder, .md files are converted to .html, while other files are copied without modification. Enable Include Subfolders to preserve the original folder structure.

Editing and Preview

You can edit Markdown documents and CSS directly within the application. Flint Site Builder supports both an in-app rendered preview and a preview in your web browser.

Key Features

  • Generate static HTML websites from Markdown documents
  • Save and load projects
  • Four HTML layouts: top, bottom, left, and right menus
  • 12 design options: Default, Unlimited Banner, and Menu Jump
  • Customizable menus and nested subcategories
  • Custom banner images and text
  • Built-in Markdown and CSS editing
  • Automatic conversion of local .md links to .html
  • Batch conversion of standalone Markdown documents to HTML
  • Preserve folder structures and copy non-Markdown files
  • In-app and browser previews
  • Korean and English user interfaces
  • Built-in sample project with preservation of existing sample files

Running the Application

Install the required package:

pip install markdown

Run the application:

python builder.py
