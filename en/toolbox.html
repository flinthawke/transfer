Flint's Toolbox

Flinthawk's toolbox is stocked with useful gear for the voyage.
It also contains a nuclear cannon, an anti-gravity cruise system, and a giant squid repeller, but those are not available to the public.

Python and EXE Run Notice
Python must be installed to run Python source files (.py).
EXE files are convenience builds that can run without installing Python. However, some tools may not provide an EXE build.
If no EXE file is available, install Python and run the source code instead.

Flint Backup

Flint Backup is a Windows backup utility that lets you back up files and folders to a specified destination using mirror backup, standard copy, or ZIP compression. You can create multiple backup slots and run them sequentially. Frequently used slot configurations can be saved as up to 8 separate presets and switched between as needed.

Version: 1.0.0

View details

Flint Site Builder

A GUI-based website builder for creating static HTML websites from Markdown documents. You can configure menus, banners, layouts, and CSS while keeping the original Markdown files unchanged, then generate the completed website in a separate output folder. Markdown documents that are not part of the top, bottom, left, or right menu layouts can also be converted into individual HTML files using the `HTML Conversion` feature.

Version: 1.0.0

View details

Flint Text Replacer
