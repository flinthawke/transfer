🛡️ Blackship Shield

공용 Windows PC용 임시 감시 도구. 다운로드하여 실행하면 로컬 대시보드가 열립니다.

보호막 엔진 다운로드

사용 순서

  1. 보호막 ZIP 다운로드
  2. 압축 해제 후 start_shield.bat 실행
  3. 로컬 대시보드에서 감시 및 세션 종료

웹사이트는 로컬 프로그램을 직접 실행할 수 없습니다. 레지스트리 기록만으로 악성 프로그램을 확정할 수 없습니다. 화면 캡처 제외는 Shield 자체 창에만 적용됩니다. 세션 정리는 전용 격리 브라우저에만 적용됩니다.

공용 PC 사용 후 점검

Chrome / Edge: Ctrl+H · Ctrl+Shift+Delete · 로그아웃 및 다운로드 파일 확인
