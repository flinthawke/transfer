플린트의 공구함

플린트호크가 항해에 쓸 만한 도구를 모아둔 공구함입니다.
원자력포, 반중력 순항장치, 대왕문어 퇴치기 등도 있지만 공개하지 않습니다.

Python 및 EXE 실행 안내
Python 소스코드(.py)를 실행하려면 Python 설치가 필요합니다.
EXE 실행파일은 Python 설치 없이 사용할 수 있도록 제공하는 편의용 배포본입니다. 다만 프로그램에 따라 EXE가 제공되지 않을 수 있습니다.
EXE 파일이 없는 경우 Python을 설치한 후 소스코드를 실행해 주세요.
Python 다운로드 (공식 홈페이지)

플린트 네트워커

인터넷 끊김이나 지연이 PC, 공유기, 외부 회선, DNS 중 어느 구간에서 발생하는지 확인하는 Windows용 네트워크 진단 도구입니다.

버전: 1.1.1

설명 및 설치 방법

플린트 백업

폴더나 파일을 지정한 위치에 미러 백업, 일반 복사 또는 ZIP 압축으로 보관하는 Windows용 백업 도구입니다. 여러 개의 백업 슬롯을 등록해 순서대로 실행할 수 있으며, 자주 사용하는 슬롯 구성을 최대 8개의 설정으로 나누어 저장하고 전환할 수 있습니다.

버전: 1.0.0

설명 및 설치 방법

플린트 사이트 빌더

Markdown 문서를 기반으로 정적 HTML 홈페이지를 제작하는 GUI 기반 사이트 제작 도구입니다. Markdown 원본은 그대로 유지하면서 메뉴, 배너, 디자인, CSS를 설정하고 완성된 사이트를 별도의 출력 폴더에 생성할 수 있습니다. 상단 / 하단 / 좌측 / 우측 메뉴형에 포함되지 않는 Markdown 문서는 `HTML 변환` 기능을 이용해 개별 HTML 문서로 변환할 수도 있습니다.

버전: 1.0.0

설명 및 설치 방법

플린트 텍스트 리플레이서

여러 텍스트 파일에 포함된 문자열을 한 번에 찾아 변경하는 도구입니다. 변경 전·후 내용을 자동으로 비교해 보여주며, 실제로 변경되는 파일만 결과 목록에 표시합니다.

버전: 1.0.0

설명 및 설치 방법

플린트 파일 리네이머

여러 파일의 이름을 한 번에 변경하는 도구입니다. 단순한 문자열 치환뿐 아니라 문자열 삭제, 앞·뒤 문자열 추가, 번호 붙이기, 이름과 번호를 이용한 일괄 변경을 지원합니다.

버전: 1.0.0

설명 및 설치 방법

플린트 스트링 파인더

여러 드라이브나 폴더에서 특정 문자열이 포함된 파일을 찾는 Windows용 GUI 검색 도구입니다.

버전: 1.1.0

설명 및 설치 방법

플린트 텍스트 인서터

여러 텍스트 파일의 문서 맨 위나 맨 아래에 동일한 문자열을 한 번에 삽입하는 도구입니다. Markdown 문서에 `<!-- poem -->` 같은 분류용 주석이나 고정된 머리말·꼬리말을 여러 파일에 일괄로 추가할 때 사용할 수 있습니다.

버전: 1.0.0

설명 및 설치 방법

플린트 아이콘 메이커

PNG, JPG, WEBP, BMP 이미지를 Windows 실행파일용 멀티사이즈 ICO 파일로 변환하는 GUI 도구입니다.

버전: 1.0.0

설명 및 설치 방법
Windows 실행 안내
Windows에서 다운로드한 실행 파일이 보안 기능에 의해 차단될 수 있습니다.
실행되지 않는 경우 파일을 마우스 오른쪽 버튼으로 클릭한 후 속성 → 일반 → 차단 해제 → 적용을 선택하고 다시 실행해 주세요.
Flint 도구는 별도의 코드 서명 인증서를 사용하지 않으므로 알 수 없는 게시자로 표시될 수 있습니다.
