플린트 스트링 파인더

버전: 1.1.0

Flint String Finder

여러 드라이브나 폴더에서 특정 문자열이 포함된 파일을 찾는 Windows용 GUI 검색 도구입니다.

사용 방법

  1. 검색 범위를 선택합니다. (현재 폴더, 내 컴퓨터 전체, 드라이브, 폴더)
  2. 찾을 문자열을 입력합니다.
  3. 필요한 경우 확장자 제한(py, md, txt 등)과 대소문자 구분 옵션을 설정합니다.
  4. 검색에서 제외할 폴더명, 파일명 또는 파일 내용 문자열이 있다면 제외 조건을 설정합니다.
  5. 검색 시작을 누릅니다.
  6. 결과를 더블클릭하면 해당 파일을 바로 열 수 있습니다.
  7. 결과를 우클릭하면 파일 또는 파일이 있는 폴더를 열 수 있습니다.

검색 제외

검색할 필요가 없는 파일이나 폴더를 제외할 수 있습니다.

  • 폴더명 제외
  • 파일명 제외
  • 특정 문자열이 포함된 파일 제외
  • 제외된 폴더의 하위 경로 전체 검색 생략

오류 로그

검색 중 접근할 수 없거나 읽지 못한 파일이 발생하면 오류 내용을 로그에 기록합니다. 로그 보기에서 오류가 발생한 파일과 원인을 확인하거나 기존 로그를 지울 수 있습니다.

주요 기능

  • 실행한 현재 폴더를 기본 검색 위치로 사용
  • 내 컴퓨터 전체 또는 특정 드라이브 검색
  • 특정 폴더 검색
  • 파일 내용 문자열 검색
  • 폴더명, 파일명, 파일 내용 검색 제외
  • 확장자 제한
  • 대소문자 구분
  • UTF-16 텍스트 파일 검색 지원
  • 현재 검사 파일, 검사 수, 발견 수, 오류 수 표시
  • 경과 시간 및 진행 상태 표시
  • 검색 중지
  • 검색 오류 로그 기록 및 확인
  • 결과 더블클릭으로 파일 열기
  • 결과 우클릭으로 파일 또는 폴더 열기
  • 긴 검색 중 플린트 선장 & 갈매기 진행 멘트
